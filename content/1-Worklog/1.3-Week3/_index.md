### Week 3 Achievements:

* Understood the data protection services:
  * Data encryption with AWS KMS
  * TLS certificates with ACM
  * Amazon Macie detecting sensitive data

* Can tell the threat detection services apart:
  * Inspector: vulnerability scanning
  * GuardDuty: unusual behaviour detection
  * Detective: root cause investigation
  * Security Hub: findings in one place

* Understood the compliance and governance tools:
  * AWS Artifact, AWS Config, Audit Manager
  * Control Tower, Service Catalog, License Manager
  * Health Dashboard, Trusted Advisor, IAM Access Analyzer

* Deployed an application on Amazon ECS: cluster, task definition, load balancer, service.

* The team decided on the project shop-ai, an e-commerce shop for computers and electronics on AWS; each member received their part of the work.

* Attended 2 events: AWS Cloud Day and AI Day Hanoi - Watch Party (29/09) and Fireside Chat with Dr. Werner (02/10).
