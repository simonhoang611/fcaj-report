### Week 1 Achievements:

* Understood the rules, regulations and way of working at the internship unit.

* Successfully created an AWS Free Tier account and completed 5 labs to earn $100 in credits.

* Practised the core services:
  * IAM: create Groups, Users and Roles and switch between roles

  * CloudShell and the AWS CLI
  * S3 static website served through CloudFront
  * RDS, DynamoDB (Console, CLI, SDK)
  * ElastiCache Redis via the AWS SDK

* Deployed AWS Managed Directory Service and joined EC2 to the domain.
