### Week 5 Achievements:

* Packaged an application as a Docker image and ran it as a container.

* Understood the cost management tools:
  * AWS Organizations: consolidated billing across accounts
  * Budgets: overspending alerts
  * Cost Explorer: cost per service
  * Pricing Calculator: estimates before deploying

* Can tell the AWS Support plans apart (Basic, Developer, Business, Enterprise).

* Understood cloud migration:
  * The 6 perspectives of AWS CAF
  * The 7 migration strategies: rehost, replatform, refactor, repurchase, retire, retain, relocate

* Know which migration tool fits:
  * Assess and track: Migration Evaluator, Application Discovery Service, Migration Hub
  * Databases: AWS DMS, SCT
  * Online transfer: DataSync, Transfer Family, Direct Connect
  * Offline transfer: Snowball Edge
